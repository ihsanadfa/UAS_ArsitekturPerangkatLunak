Penjelasan Singleton Pattern

Definisi

Singleton Pattern memastikan bahwa sebuah class hanya memiliki satu instance dan menyediakan global access point untuk instance tersebut.

Keuntungan
  • Menghemat memory dengan satu instance
  • Global access point yang konsisten
  • Thread-safe initialization
  • Lazy initialization support
Implementasi di MenuRepository
@Repository
public class MenuRepository {
    private static MenuRepository instance;
    private static final Object lock = new Object();
    
    private MenuRepository() {
        // Private constructor
    }
    
    public static MenuRepository getInstance() {
        if (instance == null) {
            synchronized (lock) {
                if (instance == null) {
                    instance = new MenuRepository();
                }
            }
        }
        return instance;
    }
}
