Design Pattern Implementation Summary
Singleton Pattern

MenuRepository menggunakan thread-safe Bill Pugh Singleton

public class MenuRepository {
  private static class SingletonHelper {
    private static final MenuRepository INSTANCE = new MenuRepository();
  }
  public static MenuRepository getInstance() {
    return SingletonHelper.INSTANCE;
  }
}
Decorator Pattern

Menambah fitur dinamis pada pesanan

IPesanan pesanan = new Pesanan(items);
pesanan = new SambalDecorator(pesanan); pesanan = new KemasanKhususDecorator(pesanan); pesanan = new PrioritasDecorator(pesanan);
