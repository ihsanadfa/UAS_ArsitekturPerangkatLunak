Implementasi 3 Design Patterns dalam Sistem Kantin Universitas

UAS Arsitektur Perangkat Lunak M. Ihsan Rizqullah Adfa - 2208107010029

Pattern Implementation Overview

Sistem ini mengimplementasikan 3 Design Patterns utama untuk menciptakan arsitektur yang scalable, maintainable, dan robust sesuai dengan prinsip-prinsip Software Architecture.

Decorator Pattern

Dynamic Order Enhancement

Implementasi

Pattern ini memungkinkan penambahan fungsionalitas tambahan pada pesanan tanpa mengubah struktur dasar objek Menu.

Fitur Decorator:
  • Tambah Sambal (+Rp 2.000)
  • Kemasan Khusus (+Rp 3.000)
  • Prioritas (+Rp 5.000)
File: decorator/PesananDecorator.java
Pattern: Concrete Decorator Implementation
Keuntungan:
  • Flexibility untuk menambah opsi baru
  • Tidak mengubah kode existing Menu
  • Kombinasi decorator yang dinamis

Singleton Pattern

Centralized Data Management

Implementasi

MenuRepository menggunakan Bill Pugh Singleton Pattern untuk memastikan hanya ada satu instance yang mengelola data menu.

Karakteristik:
  • Thread-Safe Implementation
  • Lazy Initialization
  • Memory Efficient
File: repository/MenuRepository.java
Pattern: Bill Pugh Singleton
Keuntungan:
  • Konsistensi data di seluruh aplikasi
  • Kontrol akses terpusat ke data menu
  • Efficient memory usage

Factory Pattern

Payment Object Creation

Implementasi

Factory Method Pattern digunakan untuk menciptakan objek pembayaran berdasarkan tipe yang dipilih pengguna.

Payment Types:
  • Tunai (Kasir)
  • QRIS (Digital)
  • Transfer Bank
File: factory/PembayaranFactory.java
Pattern: Factory Method Implementation
Keuntungan:
  • Extensibility untuk payment baru
  • Loose coupling antara client dan concrete classes
  • Centralized object creation logic
